# Implementation status

Implemented in this starter:
- Responsive Ukrainian dark-mode dashboard
- Manual deal entry and deletion
- Profit, total-cost, ROI and margin math (profit and ROI are shown in table/snapshot)
- Search, category filter, minimum-profit filter
- Browser localStorage persistence
- CSV import for a documented simple column format
- External OLX search link generation
- Clear demo labeling and explicit no-scraping/no-automatic-feed status

Not implemented yet:
- Automatic ingestion of third-party listings
- Supabase auth, database and row-level security
- Scheduled jobs, Telegram bot, payment flow, subscription gating
- Waitlist backend, privacy/terms review, analytics
- Production tests and CI

Before paid launch: do not charge until the data source, core workflow, access control, privacy notices and payment handling are implemented and tested.
